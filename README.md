# Cafe Hermes Bot — Railway

نسخه مستقل ربات کافه هرمس برای استقرار روی Railway. کد ربات اصلی در مخزن `TELEGRAMBOT` دست‌نخورده می‌ماند.

## اجرا روی Railway

1. این مخزن را در Railway به‌عنوان یک **Worker Service** از GitHub متصل کنید.
2. یک Volume بسازید و آن را روی مسیر `/app/data` متصل کنید.
3. در Variables مقادیر زیر را تنظیم کنید:
   - `API_ID`: شناسه Telegram API
   - `API_HASH`: هش Telegram API
   - `BOT_TOKEN`: توکن ربات
   - `ADMIN_IDS`: شناسه عددی ادمین‌ها، با کاما جدا شوند
   - `PAYMENT_CARD`: شماره کارت
   - `PAYMENT_NAME`: نام صاحب کارت
   - `DATABASE_PATH`: مقدار `/app/data/cafe_hermes.db`
4. برای بازیابی و پشتیبان‌گیری تلگرامی، متغیرهای `STORAGE_CHAT_ID`، `STORAGE_CONFIG_CHAT_ID` و `STORAGE_FILES_CHAT_ID` را با شناسه سه کانال خصوصی فعلی تنظیم کنید. مقادیر پیش‌فرض فعلی کد حفظ شده‌اند؛ در صورت نیاز می‌توانید آن‌ها را override کنید. ربات باید در هر سه کانال دسترسی ادمین داشته باشد.
5. دستور اجرا به‌صورت خودکار `python app.py` است.

## نکات مهم

- فایل `config.json` فقط تنظیمات عمومی و غیرمحرمانه دارد؛ توکن، API Hash، شماره کارت و شناسه ادمین‌ها را داخل GitHub قرار ندهید.
- اطلاعات پرداخت از متغیرهای محیطی Railway خوانده می‌شود و پس از راه‌اندازی در تنظیمات خصوصی دیتابیس ذخیره می‌شود.
- دیتابیس SQLite روی Volume مسیر `/app/data` نگهداری می‌شود. Volume را حذف نکنید.
- اگر نسخه قبلی ربات با همین Bot Token فعال است، قبل از اجرای نسخه Railway آن را متوقف کنید تا دو پردازش هم‌زمان با یک توکن polling نکنند.
- در اولین راه‌اندازی، اگر دیتابیس محلی خالی باشد، ربات طبق منطق فعلی تلاش می‌کند اطلاعات را از کانال‌های ذخیره‌سازی تلگرام بازیابی کند. اگر بازیابی معتبر انجام نشود، برای جلوگیری از شروع با دیتابیس خالی متوقف می‌شود.
