# Cafe Hermes Bot — Railway

نسخه مستقل ربات کافه هرمس برای استقرار روی Railway. مخزن اصلی دست‌نخورده می‌ماند.

## اجرا روی Railway

1. مخزن را در Railway به‌عنوان **Worker Service** متصل کنید.
2. یک Volume روی مسیر `/app/data` بسازید.
3. فقط این متغیرهای لازم را در Railway تنظیم کنید:
   - `API_ID`: شناسه Telegram API
   - `API_HASH`: هش Telegram API
   - `BOT_TOKEN`: توکن ربات
   - `DATABASE_PATH`: `/app/data/cafe_hermes.db`
4. شناسه ادمین، شماره کارت، نام صاحب کارت و تنظیمات اصلی هرمس از قبل در `config.json` قرار دارند؛ نیازی به واردکردن دوباره آن‌ها در Railway نیست.
5. تنظیمات کانال‌های بکاپ تلگرامی از مقادیر پیش‌فرض فعلی استفاده می‌کنند و فقط در صورت نیاز می‌توان آن‌ها را با متغیرهای `STORAGE_CHAT_ID`، `STORAGE_CONFIG_CHAT_ID` و `STORAGE_FILES_CHAT_ID` تغییر داد.
6. دستور اجرا `python app.py` است.

## نکات مهم

- دیتابیس SQLite روی Volume مسیر `/app/data` نگهداری می‌شود؛ Volume را حذف نکنید.
- اگر نسخه قبلی ربات با همین Bot Token فعال است، پیش از اجرای Railway آن را متوقف کنید تا دو پردازش هم‌زمان polling نکنند.
- در اولین راه‌اندازی، اگر دیتابیس محلی خالی باشد، ربات طبق منطق فعلی تلاش می‌کند اطلاعات را از کانال‌های ذخیره‌سازی تلگرام بازیابی کند. اگر بازیابی معتبر انجام نشود، برای جلوگیری از شروع با دیتابیس خالی متوقف می‌شود.
